# Stickman Shorts — ролики-метафоры со светящимися стикменами

Готовый пайплайн лежит в `promo/stickman/`:

| Файл | Что делает |
|---|---|
| `engine.js` | движок: фигура со скелетом и позами, ходьба/бег, текст со свечением, блоки, звезда, свечения, фон, монтаж сцен с затемнениями |
| `ep01.html` | эпизод 1 «Start Today» — образец, копировать для новых эпизодов |
| `render.mjs` | `node render.mjs epNN` → кадры 30 fps → `epNN.mp4` (+ `epNN.json` с началами сцен); `--stills 1,4,8` — быстрые проверочные кадры |
| `music.py` | `python3 music.py epNN` → `epNN.wav`: пэд Am–F–C–G, мягкое «пианино», удары на сменах сцен (без чужой музыки) |

## Порядок работы

1. **Тема и 4–6 метафор.** Одна сцена = одна мысль, 5–7 секунд. Лучшие метафоры — противопоставление двух фигур (Мечтать / Делать, Мотивация / Дисциплина, Ждать / Начать) или превращение (пропасть «Страх» сжимается в трещину; корни растут под землёй, потом выстреливает дерево).
   Придумывать **свои** метафоры. Не копировать сцены, надписи и водяной знак чужого канала — берём только стиль.
2. **Скопировать `ep01.html` → `epNN.html`**, переписать функции сцен `sN(ctx, t)` и список `timeline([...])`. `t` — локальное время сцены в секундах.
3. **Проверить кадры:** `node render.mjs epNN --stills 1,3,5,...` и посмотреть png (собрать в лист: `ffmpeg -pattern_type glob -i 'stills/epNN_*.png' -vf "scale=270:-1,tile=8x2" sheet.png`).
   Отдельно проверить движение: плотная раскадровка `fps=6` по видео.
4. **Рендер и звук:**
   ```bash
   cd promo/stickman
   node render.mjs epNN          # кадры + mp4 без звука, пишет epNN.json
   python3 music.py epNN         # epNN.wav по длительности и сменам сцен
   ffmpeg -y -i epNN.mp4 -i epNN.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 256k -shortest -movflags +faststart out.mp4 && mv out.mp4 epNN.mp4
   ```
   1000 кадров рендерятся ~30 с. Playwright берётся глобальный (`npm root -g`).
5. Живой предпросмотр в браузере: `epNN.html?play`, конкретный момент: `epNN.html?t=12.5`.

## Стиль (выжимка из референсов)

- **Фон** чистый чёрный, мягкое серое пятно света по центру, редкие пылинки. Никаких градиентных обоев.
- **Фигуры** — толстые конечности со скруглёнными концами, голова-шар с объёмным бликом, белое свечение. Дальние рука/нога темнее (глубина). Рост фигуры ≈ 250 px на кадре 1080×1920.
- **Цвета:** белый/серые — основное; **золото `#f2a516`** — «правильный путь», герой после победы; **красный** — страх, провал; зелёный — редко, только «WIN». Победа = фигура плавно перекрашивается в золото.
- **Язык — английский.** Короткие простые фразы (до ~32 символов в строке), без сленга.
- **Без брендинга:** никаких логотипов, водяных знаков, названий сайтов и ссылок в кадре.
- **Текст:** Manrope 700/800, 44–62 px, по центру сверху (y≈420–600), белый со свечением; вторая строка-вывод появляется позже, часто золотом. Ярлыки над противопоставлением — капсом с разрядкой (`spacing: 4`).
- **Ритм:** сцена 5–7 с, затемнение между сценами 0.35 с; подпись появляется в первые 0.3 с, поворот смысла — на 3–4 секунде, развязка в последние 2 с. В конце — карточка с выводом (например «Start today.») 2–3 с, без логотипа.
- **Земля** — тонкая серая линия (y≈1100–1250); счётчики дней/«ДЕНЬ 365» — мелким серым капсом.

## API движка (`window.SM`)

- `fig(ctx, {x, y, s, dir, pose, color, alpha, glow})` — фигура стоит ногами на `y`; возвращает мировые координаты суставов (`handN`, `headC`, …) — к ним крепить реквизит.
- Позы `POSE.*`: `stand, slump, lookUp, lookDown, scared, sitHug, sitLook, crouch, jump, reach, cheer, water, lookBackUp`.
  Свои позы — объект углов (радианы от вертикали вниз, «+» вперёд): `lean, head, aN/fN, aF/fF` (плечо/локоть ближней/дальней руки), `tN/kN, tF/kF` (бедро/колено), `hip` — высота таза для сидячих поз.
- `mix(p, q, k)` — плавный переход между позами; `walk(phase, amp, run)` — цикл шага/бега (phase = x / 50 даёт шаг без проскальзывания).
- `seg(t, a, b, E.out)` — прогресс 0..1 на отрезке времени с плавностью (`E.lin/in/out/inOut/back/sine`).
- `caption(ctx, str, x, y, t, t0, t1?, {size, color, weight, spacing, align})` — подпись с появлением; `text(...)` — статичный текст.
- `line, block, star, glowDot` — линии со свечением, объёмные блоки/ступени, звезда, световое пятно.
- `timeline([{dur, draw, bg}])` → `{total, list, draw(ctx, T)}` (опция `watermark` есть, но не используем).

## Идеи следующих эпизодов

- «Motivated vs Disciplined» — календарь, один бросает на 3-й день, другой тренируется до 365-го.
- «Сравнивать себя с другими» — бегун оглядывается на соседнюю дорожку и спотыкается; «Run your own race».
- «Your circle» — качели: одни тянут вниз, другие поднимают.
- «Procrastination» — маленький снежный ком задач каждый день становится лавиной.
- «One step» — лестница в тумане: видна только следующая ступень, но её достаточно.
